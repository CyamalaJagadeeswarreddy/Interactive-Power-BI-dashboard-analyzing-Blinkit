📌 Project
An interactive **Power BI dashboard** developed to analyse Blinkit-style retail sales, outlet performance, product categories, and customer ratings — transforming raw sales data into clear, actionable business insights.

## 🎯 Objectives
- 📈 Analyse overall sales and outlet performance
- 🛍️ Compare product categories and fat content
- 🏪 Analyse outlet size, type, and location
- 📅 Identify sales and rating trends by establishment year
- 💡 Provide interactive business insights

 🛠️ Technologies Used

`Power BI Desktop` · `Power Query` · `DAX` · `Data Visualisation` · `Excel Dataset`

🔄 Workflow
Dataset → Power Query → Data Cleaning → Data Model → DAX → Visualisations → Slicers → Bookmarks → Interactive Dashboard


---

## 📈 Analysis Areas

`Item Type` · `Item Fat Content` · `Outlet Type` · `Outlet Size` · `Outlet Location` · `Establishment Year` · `Sales` · `Rating`
